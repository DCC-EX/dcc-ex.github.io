# EX-CommandStation Add-Ons

Built into our \|EX-CS\| command station firmware are a number of
add-ons that provide additional features and functionality. These
add-ons are developed and maintained by the DCC-EX team and are
available for free to all users of our command stations.

- \|EX-R\| is an \"EXtended Railroad Automation Instruction Language\"
  that can easily be used to describe sequential command \'sequences\'
  to automatically take place on your model layout. \|BR\| \|BR\|
- **Track Manager** is an integral part of the command station software
  that is responsible for, among other things:
  - Managing track power state.
  - Monitoring track overloads and shorts.
  - Handling user or EXRAIL commands to switch track status, including
    to and from PROG, MAIN and **DC**. \|BR\| \|BR\| \|EX-CS\| is now a
    dual Command Station for both Digital Command Control (DCC) and
    analogue (DC) layouts.
