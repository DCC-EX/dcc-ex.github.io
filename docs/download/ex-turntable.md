# EX-Turntable

\|SUITABLE\| \|tinkerer\| \|engineer\| \|support-button\|

\|EX-TT\| is a fully integrated turntable controller, using an Arduino
microcontroller to drive a stepper controller and motor to spin the
turntable bridge.

You can now use \|EX-I\| to download and install \|EX-TT\|.
