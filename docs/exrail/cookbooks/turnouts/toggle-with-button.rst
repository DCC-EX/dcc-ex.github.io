*********************************************
Toggle turnouts/points with button or sensor
*********************************************

|SUITABLE| |tinkerer| |engineer| |support-button|

A turnout/point of any type can be toggled by a button or sensor of any type.

.. code-block:: cpp

    ONBUTTON(173) TOGGLE_TURNOUT(6) DONE
