# G Scale Climax - DCC-EX

\|tinkerer\|

This project is a G Scale Climax locomotive that has been converted to
DCC control using \|DCC-EX\|. The conversion includes:

- Installing a DCC-EX EX-CommandStation inside the Loco.
- Having the Command Station output DC (PWM) directly to the existing
  circuitry in the loco.
- Using an inexpensive battery in a following carriage.
- Using the Engine Driver app on my phone to talk directly to
  EX-CommandStation in the loco, which would in turn control the loco.

See <https://sites.google.com/view/g-scale-climax-dcc-ex/home> for more
details and photos of the project.
