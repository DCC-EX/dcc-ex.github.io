# Frequently Asked Questions (FAQ)

\|SUITABLE\| \|conductor\| \|tinkerer\| \|engineer\| \|support-button\|
\|

This is a list of **Frequently Asked Questions** that we answer on our
various support channels:

  Question                                          Answer
  ------------------------------------------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Can I run a loco on the programming track?        Yes, by issuing the command `<1 JOIN>` via the serial console. \|BR\| This is intended to be temporary, for running a loco from a programming track onto your layout, not for normal running of the layout. \|BR\| \|BR\| (In \|Engine driver\| you can `Request Loco ID`{.interpreted-text role="guilabel"} which will also temporarily allow the loco to be driven from the programming track. see `/throttles/driveaway`{.interpreted-text role="doc"} for more information.)
  Why Can\'t I Put an EXRAIL Script on an SDCard?   Being able to read an SD card on the Arduino platforms requires a significant amount of code because there is no operating system or file system which we would take for granted on a PC. We simply don't have enough free memory on an Arduino to hold that code. \|BR\| \|BR\| See `exrail/about:why can't i put a script on an sdcard?`{.interpreted-text role="ref"} for more information.
