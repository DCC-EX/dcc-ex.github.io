# DCC-EX Simple Throttle (Physical)

\|SUITABLE\| \|tinkerer\| \|engineer\| \|support-button\|

To accompany my mimic panel\'s serial throttle (see [DCC-EX
Tri-Throttle](https://petegsx-projects.github.io/tri-throttle/index.html)
\|EXTERNAL-LINK\| ), I decided a very simple WiFi enabled, palm-sized
throttle I could walk around the layout with would be a very handy
addition, hence the creation of this DCC-EX Simple Throttle.

PeteGSX

Note that there is an option to run this on an STM32F103C8 Bluepill via
a serial connection instead.

<https://petegsx-projects.github.io/simple-throttle/index.html>
