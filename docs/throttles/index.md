> BT = Bluetooth \|BRxa\| Free = No additional cost for full
> functionality. \|BRxa\| Paid = Payment required for any usage.
> \|BRxa\| Free/Paid = Both Free and Paid versions are available. The
> free version usually has limited features. \|BRxa\| Open Source =
> Designs and Source code are available to view, modify and build your
> own. \|BRxa\| However the hardware to build it is not free. \|BRxa\|
> Native = Uses the DCC-EX Native protocol/commands.[^12] \|BRxa\| WiT =
> Uses the WiThrottle protocol.[^13] \|BRxa\| Web = Requires the use of
> a Web Browser. \|BRxa\| Physical = A dedicated separate physical
> device. Not an app running on a standard smart device. \|BRxa\|
> Android = A phone or tablet running the Google Android operating
> system. \|BRxa\| iOS = An Apple iPhone or tablet running the iOS
> operating system. \|BRxa\| MacOS = An Apple laptop or PC. \|BRxa\| Win
> = Windows 7 and above. \|BRxa\| DIY = Do it Yourself. Requires you to
