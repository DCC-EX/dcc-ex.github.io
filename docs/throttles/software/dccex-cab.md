# DCC-EX CAB

![Android Logo](/_static/images/throttles/icon_android.png)

![iOS Logo](/_static/images/throttles/icon_ios.png)

This is an Android and iOS App. One of the major benefits of DCC-EX CAB
is that it speaks the \|DCC-EX Native Commands\| natively. This means it
is fast and can take advantage of some features that exist in the
\|EX-CS\| not implemented in other APIs.

You can find it in the Google Play Store: [DCC-EX CAB Android
App](https://play.google.com/store/apps/details?id=com.gothicmaestro.dccexcab)

You can find it in the Apple App Store: [DCC-EX CAB iOS
App](https://apps.apple.com/us/app/dcc-ex-cab/id6695754417?uo=2)
