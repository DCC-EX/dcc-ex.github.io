# Railroad Automation

\|SUITABLE\| \|conductor\| \|tinkerer\| \|engineer\| \|support-button\|

Railroad Automation (RRA) is a command and control software package, for
DCC (Digital Command Control) model railroads, specifically designed to
work with the Loconet network bus. Runs on Microsoft\'s .NET framework
stack supported by Windows 7 and above.

Note: *Requires IoTT Red Hat*
