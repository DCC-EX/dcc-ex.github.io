This is an iOS App from Germany. One of the major benefits of SRCPClient
is that it speaks the \|DCC-EX Native Commands\| natively (see our
`/reference/software/command-summary-consolidated`). This means it is fast and can take advantage of some
features that exist in the \|EX-CS\| not implemented in other APIs. Is
also can connect to a WiThrottle server so you can use it with \|JMRI\|
too.

Please visit their website: <https://www.io-expert.com/>

You can find it in the App Store: [SRCP Client for
iOS](https://www.io-expert.com/srcpclientios/index.html)
\|EXTERNAL-LINK\|

## Features 

- Supports the \|DCC-EX Native Commands\| natively
- Supports \|WiThrottle Protocol\|
- Connect via WiFi

## Requirements 

- A \|EX-CS\| (Mega based for WiFi)
- An iOS Cell Phone or Tablet
- A Wifi Shield (or other ESP8622 solution) if you want to connect using
  WiFi
  `Wifi Setup </ex-commandstation/diy/wifi-setup>`
