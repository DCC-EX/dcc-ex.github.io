# WiThrottle protocol library - WiThrottleProtocol

\|SUITABLE\| \|tinkerer\| \|engineer\| \|support-button\|

A WiThrottle protocol library is available to help develop throttle apps
on Arduino (primarily ESP32) hardware.

The library implements the WiThrottle protocol (as used in many commands
Staions including the \|DCC-EX\| \|EX-CS\|, JMRI, LnWi), allowing a
device to connect to the server and act as a client (such as a hardware
based throttle).

Details of the library, including instructions and examples, [is
available here](https://github.com/flash62au/WiThrottleProtocol)
